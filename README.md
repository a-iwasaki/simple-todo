# simple-todo

ブラウザだけで動くシンプルな TODO アプリです。ビルドや依存パッケージは不要です。

## 使い方

`index.html` をブラウザで開いてください。

| 操作 | 方法 |
| --- | --- |
| 追加 | 入力して Enter、または「追加」 |
| 完了 / 未完了 | チェックボックス |
| 編集 | 「編集」、または文字をダブルクリック |
| 編集の確定 / 取り消し | Enter（または入力欄の外をクリック） / Escape |
| 削除 | 「削除」 |
| 絞り込み | 「すべて」「未完了」「完了」 |
| 完了分の一括削除 | 「完了済みを削除」 |

削除は取り消せません。

## データの保存先

タスクはブラウザの `localStorage`（キー: `simple-todo:v1`）に保存されます。
サーバーには送信されません。別のブラウザや端末とは共有されず、
ブラウザのサイトデータを削除するとタスクも消えます。

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | 画面の構造 |
| `style.css` | 見た目（OS の設定に合わせてダークモード対応） |
| `todo.js` | TODO データの操作（DOM に依存しない） |
| `app.js` | 描画、イベント処理、保存 |
| `test/todo.test.js` | `todo.js` のテスト |

## テスト

Node.js 18 以降で実行できます。

```sh
node --test
```
